Authorization model:
All users have baseline organization role Viewer.
Elevated Edit access is granted only through team-scoped folder permissions.

Source inconsistency noted:
The supplied material gives Development Team VIEW access to System Monitoring
in its folder-permission matrix, while its later user test says the developer
should have NO access. This implementation follows the explicit permission matrix.
